# 🏅 Olympic Games Data Analysis | Power BI Dashboard
---

## 📌 Project Overview

The Olympic Games are among the world's largest international sporting events, bringing together athletes from different countries to compete across multiple sports.

This project focuses on analyzing historical Olympic data using **Microsoft Power BI** to uncover meaningful insights into medal achievements, country performance, athlete participation, sports, events, host countries, and gender representation.

The project features **6 interactive dashboard pages** designed to transform raw historical data into meaningful visual insights through KPIs, charts, tables, and interactive filters.

## 🎯 Project Objectives

- Analyze historical Olympic medal trends.
- Identify top-performing countries and athletes.
- Compare medal achievements across different sports.
- Understand athlete participation across age groups and genders.
- Analyze Olympic hosting patterns and host-country performance.
- Build an interactive Power BI dashboard for data-driven exploration.

## 🔍 Key Insights & Findings

The following insights are based on the dashboard analysis:

| KPI | Result |
|---|---:|
| Olympic Editions | 64 |

| Recorded Events | 964 |
| Total Medal Records | 20,654 |
| Athlete Records | Approximately 156K |

### Major Findings

**1. Country Performance**
- The United States leads the displayed medal ranking with 3,009 medals.
- The Soviet Union follows with 1,204 medals.
- Germany ranks third with 1,098 medals.

**2. Medal Distribution**
- Bronze: 7,176
- Gold: 6,753
- Silver: 6,725

**3. Sports Performance**
- Athletics leads with 4,509 medals.
- Swimming follows with 3,278 medals.
- Rowing contributes 3,074 medals.

**4. Athlete Participation**
- Approximately 156K athlete records are displayed.
- The 20–25 age group has the highest displayed participation, with 85,579 records.
- Male athlete records account for approximately 116K, while female records account for approximately 40K.

**5. Gender Representation**
- Male medal records: 69.93%
- Female medal records: 30.07%
